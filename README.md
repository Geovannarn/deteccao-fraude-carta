# Deteccao-Fraude 

Projeto de Machine Learning para detecção de transações fraudulentas com cartão de crédito, utilizando diferentes algoritmos de classificação e técnicas para lidar com o forte desbalanceamento entre transações legítimas e fraudulentas.

#Dataset 
Projeto utiliza o Credit Card Fraud Detection Dataset disponibilizado pelo TensorFlow. 

#Modelos 
Foram utilizados e comparados diferentes modelos de classificação: 
- Logistic Regression
- Random Forest
- XGBoost

#Tratamento de Desbalanceamento 
Como transações fraudulentas representam uma pequena parcela do dataset, foram consideradas técnicas de balaceamento, incluindo o Random Under-Sampling e Synthetic Minority Over-sampling Technique.
